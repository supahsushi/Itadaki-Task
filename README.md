# Itadaki Task

A Sushi Champloo habit tracker concept for sushi lovers. Add a timed task and the chef serves nigiri to your plate. Finish the task and you get to eat it.

## Asset Slots

The first version renders polished SwiftUI fallback art, and is ready for your brand assets in the asset catalog:

- `ChefMorning`
- `ChefNoon`
- `ChefNight`
- `BackgroundMorning`
- `BackgroundNoon`
- `BackgroundNight`

Add those as image sets in `ItadakiTask/Assets.xcassets`.
